Always present a plan or description of intended changes first, then wait for the user to reply with "go" before touching any code or making any edits.

**Why:** User explicitly requested this to stay in control of what changes are made and when.

**How to apply:** Every session, for every task — describe what you plan to do, then stop and wait. Only proceed after the user sends "go" (or an equivalent explicit confirmation).
